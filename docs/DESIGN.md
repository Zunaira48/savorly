# Design System

## Color Palette — "Dark Luxury Kitchen"
| Role | Hex |
|---|---|
| Background | #0D0D0F |
| Elevated surface | #16161A |
| Primary accent | #F5A623 |
| Secondary accent | #E85D4C |
| Success | #7FB88A |

## Typography
Plus Jakarta Sans — chosen for its modern, slightly rounded character
that reads as premium without feeling corporate.

## Component Philosophy
Every recipe card follows the same pattern regardless of context
(trending, search results, favorites, related) — one render function,
reused everywhere, so visual consistency is structural rather than
something that has to be manually maintained.
