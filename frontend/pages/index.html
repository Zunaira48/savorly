About Savorly

Savorly is a recipe discovery platform built to make cooking decisions effortless. With over 5,500 curated recipes spanning breakfast to dessert, quick weeknight meals to weekend projects, we help you find exactly what you're craving — without the endless scrolling.

This project was built as a full-stack portfolio piece, combining a Node.js/Express backend with a vanilla JavaScript frontend, backed by a SQLite database of real recipe data.
